# The Sanctuary

An interactive study of the wilderness sanctuary: every piece of furniture, the daily and yearly services, the feasts, the high priest and the 2,300-day prophecy. Every reference shows its King James Version text when you point at it.

## Run locally

```
npm install
npm run dev        # development
npm run build && npm start   # production (Express serves dist/ on $PORT)
```

## Content

- `src/data/symbols.ts` – the ten pieces of furniture
- `src/data/extras.ts` – services, feasts, priest, prophecy, quiz
- `src/data/verses.json` – KJV text for every reference, generated by `npm run verses -- path/to/en_kjv.json`
- `src/art/` – drop finished furniture artwork here (see the README inside)

## Deploy

Railway: Node service, build `npm run build`, start `npm start`. Health check at `/health`.
